# OSS Knowledge Platform (BrainClone) - 멀티 에이전트 RAG 포털

**기간**: 2025년 6월 - 현재 (진행 중)  
**상태**: 1단계 운영 중, 지속적 고도화  
**역할**: Tech Lead (Full-Stack & AI Platform)  
**시연**: [시연 동영상 보기](https://www.youtube.com/watch?v=ZQj75tLnvwk)

---

## 개요

OSS Knowledge Platform (BrainClone)은 조직 지식 디지털화 기반 멀티 에이전트 RAG 포털입니다. 신입 독립시간 18개월, 장애 대응시간 2~3시간 등 조직 생산성 저하 문제를 해결하기 위해 Neo4j 기반 지식그래프로 사내 OSS 시스템 문서·운영 지식·장애 이력을 모델링하고, Agentic/Graph RAG 기반 지식 검색 포털을 구축하며, 다른 AI 서비스의 공통 인지 기반 역할을 수행합니다.

## 문제 정의

- 신입 직원의 **18개월 독립 시간**
- **2~3시간 장애 대응 시간**으로 인한 골든타임 놓침
- 개별 전문가의 머릿속에 갇힌 **암묵지**
- 여러 시스템과 문서에 분산된 **단편적 지식**
- 전문가 지식에 대한 **24/7 접근 불가**

## 솔루션 아키텍처

### 다층 지식 구조

시스템은 세 가지 상호 보완적인 지식 표현 시스템을 통합합니다:

1. **벡터 데이터베이스 (Qdrant)**: 관련 문서 및 콘텐츠를 찾기 위한 의미 유사성 검색
2. **그래프 데이터베이스 (Neo4j)**: 크로스 도메인 지식 연결을 위한 관계 모델링
3. **메모리 시스템 (mem0)**: 맞춤형 응답을 위한 사용자 프로파일링 및 개인화

### Agentic/Graph RAG 구현

- **벡터 검색**: 임베딩을 사용한 의미 유사성 매칭
- **그래프 순회**: 관계 기반 지식 발견
- **크로스 도메인 검색**: 포괄적인 지식 접근을 위해 두 접근 방식을 결합

### 멀티 에이전트 시스템

- **의도 분류 에이전트**: 사용자 쿼리를 이해하고 적절한 에이전트로 라우팅
- **작업 계획 에이전트**: 복잡한 쿼리를 관리 가능한 단계로 분해
- **지식 검색 에이전트**: 다양한 지식 도메인을 위한 전문 에이전트
- **응답 생성 에이전트**: 여러 소스의 정보를 종합

### AI-전문가 하이브리드 접근

- **80% LLM 자동화**: 빠르고 확장 가능한 지식 그래프 구축
- **20% 전문가 검증**: 정확성과 품질 보장
- **지속적 학습**: 전문가 피드백으로 시간이 지나면서 시스템 개선

## 주요 기능

### 1. 의도 분류 및 작업 계획

- 자연어 쿼리에서 사용자 의도를 자동으로 분류
- 복잡한 작업을 순차적 단계로 분해
- 쿼리를 적절한 전문 에이전트로 라우팅

### 2. 개인화된 응답

- mem0를 사용한 사용자 프로파일링 및 컨텍스트 추적
- 사용자 역할 및 이력에 기반한 맞춤형 응답 제공
- 사용자 상호작용에서 학습하여 관련성 향상

### 3. 설명형 검색

- 투명한 지식 검색 프로세스
- 추론 경로 및 출처 표시
- 설명 가능성을 통해 사용자 신뢰 구축

### 4. 24/7 접근

- 항상 사용 가능한 지식 포털
- 기본 쿼리에 대한 인간 전문가 의존성 없음
- 필요시 복잡한 문제를 전문가에게 에스컬레이션

## 기술 구현

### 프론트엔드
- **Vue 3** 및 TypeScript
- 실시간 스트리밍 응답
- 인터랙티브 지식 그래프 시각화

### 백엔드

- 마이크로서비스 아키텍처

### 데이터 레이어
- **Neo4j**: 지식 그래프 저장 및 순회
- **Qdrant**: 벡터 임베딩 및 유사성 검색
- **PostgreSQL**: 전통적인 관계형 데이터

- **커스텀 프롬프트 엔지니어링**: 의도 분류 및 작업 계획을 위한 최적화된 프롬프트

### 인프라

- **ArgoCD**: GitOps 기반 배포
- **Jenkins**: CI/CD 파이프라인
- **GitLab**: 소스 코드 관리

## 내 역할 및 기여

Tech Lead로서 다음을 담당했습니다:

1. **아키텍처 설계**: 벡터, 그래프, 메모리 시스템을 통합한 다층 지식 구조 설계
2. **시스템 통합**: Qdrant, Neo4j, mem0의 통합 구현
3. **에이전트 개발**: 의도 분류, 작업 계획, 지식 검색 에이전트를 포함한 멀티 에이전트 시스템 구축
4. **RAG 구현**: 벡터 검색과 그래프 순회를 결합한 Agentic/Graph RAG 시스템 개발
5. **개인화**: mem0 기반 사용자 프로파일링 시스템 구현
6. **프로덕션 롤아웃**: PoC → 베타 → 1단계 프로덕션까지 기술 구현 주도

## 도전 과제 및 해결책

### 도전 과제 1: 여러 지식 시스템 통합

**문제**: 벡터 DB, 그래프 DB, 메모리 시스템은 각각 다른 강점과 쿼리 패턴을 가지고 있습니다. 이를 일관된 아키텍처로 통합하는 것은 복잡했습니다.

**해결책**: 다음을 수행하는 통합 지식 레이어 설계:
- 의미 유사성을 위한 벡터 검색 사용
- 관계 발견을 위한 그래프 순회 사용
- 개인화를 위한 메모리 시스템 사용
- 쿼리 유형에 따라 결과를 지능적으로 결합

### 도전 과제 2: 정확성 vs. 확장성

**문제**: 수동 지식 그래프 구축은 정확하지만 확장되지 않습니다. 자동화된 구축은 빠르지만 오류가 있을 수 있습니다.

**해결책**: AI-전문가 하이브리드 접근 방식 구현:
- LLM을 사용한 80% 자동화 구축
- 중요한 노드에 대한 20% 전문가 검증
- 피드백 루프를 통한 지속적 개선

### 도전 과제 3: 온보딩 시간 단축

**문제**: 신입 직원이 독립적으로 되기까지 18개월이 걸리며, 시니어 동료에 크게 의존합니다.

**해결책**: 다음을 제공하는 24/7 접근 가능한 지식 포털 생성:
- 일반적인 질문에 대한 즉각적인 답변 제공
- 단계별 절차 표시
- 관련 지식을 자동으로 연결
- 학습 진행 상황 추적

## 결과 및 영향

### 비즈니스 임팩트
- **온보딩 시간 단축**: 신입 직원이 더 빠르게 생산적이 됨
- **빠른 장애 대응**: 골든타임 응답 가능 (중요한 시간 창 내)
- **전문가 시간 확보**: 전문가가 반복적인 질문 대신 복잡한 문제에 집중 가능
- **지식 보존**: 암묵지가 이제 디지털화되어 접근 가능

### 기술 성과
- **PoC → 베타 → 1단계** 운영 롤아웃 성공적으로 실행
- 다른 AI 서비스를 위한 **공통 인지 기반**으로 플랫폼 확립
- 프로덕션 환경에서 **확장성** 및 **안정성** 입증

### 조직 역량
- **암묵지 디지털화**를 재사용 가능한 자산으로 전환
- 모든 직원을 위한 **24/7 전문가 접근**
- 더 쉬운 지식 접근을 통한 **직원 만족도 증가**
- 더 빠른 문제 해결을 통한 **고객 만족도 개선**

## 사용 기술

**프론트엔드**: Vue 3, TypeScript  
**백엔드**: Spring Boot, FastAPI, Python  
**데이터베이스**: Neo4j (Graph DB), Qdrant (Vector DB), PostgreSQL, mem0  
**AI/ML**: Azure OpenAI (GPT-4.1-mini, text-embedding-3-large/small)  
**인프라**: Azure Kubernetes, ArgoCD, Jenkins, GitLab  
**프로토콜**: MCP (Model Context Protocol)

## 주요 학습 내용

1. **멀티 에이전트 시스템**: 에이전트 통신, 작업 분해, 조정에 대한 깊은 이해
2. **Graph RAG**: 우수한 지식 검색을 위해 벡터 및 그래프 접근 방식 결합
3. **지식 그래프 모델링**: 조직 지식을 모델링하는 모범 사례
4. **엔터프라이즈 AI 플랫폼**: 안정성과 확장성을 갖춘 프로덕션급 AI 시스템 구축
5. **기술 리더십**: 개념부터 프로덕션까지 복잡한 프로젝트 주도

## 향후 개선 사항

- 외부 에이전트 연결을 위한 A2A (Agent-to-Agent) 프로토콜 통합
- 더 정교한 메모리 모델을 사용한 향상된 개인화
- 전문가 지식 공유를 위한 실시간 협업 기능
- 지식 사용 패턴에 대한 고급 분석
